# openMWR

openMWR is a Python package for training a neural network-based retrieval for a HATPRO microwave radiometer.

It includes tools for generating training datasets, training and evaluating retrievals, and applying them operationally.

See the [documentation](https://dschlebruegge.github.io/openMWR/) for installation
and the user guide.
