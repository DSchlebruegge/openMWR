# torchMWRT

torchMWRT is a PyTorch translation of the microwave radiative-transfer core of
[PyRTlib](https://github.com/SatCloP/pyrtlib). It supports batched atmospheric
profiles, GPU acceleration and automatic differentiation through tensor outputs.

Install with `python -m pip install torchMWRT`. See the
[documentation](https://dschlebruegge.github.io/openMWR/user_guide/torchMWRT_demo.html)
for examples and scientific limitations.

Development, tests and documentation share the
[openMWR repository](https://github.com/DSchlebruegge/openMWR).
