# Version 0.1 checkpoint reference

`checkpoint_01.pt` contains small zenith NN, BLS NN, MLR and spectral checkpoints,
standardized inputs and the corresponding predictions generated by openMWR 0.1
at commit `3a366973a7356b811eb93b39e416c2519113a88f`.

Weights and normalization are assigned explicitly. No training or external data
is used. The BLS case uses the old implicit angle grid. Neural profile cases use
the old implicit height weights. Checkpoints have no recipe or model-class tag.
The source and expected results are independent of the current loaders.

To deliberately regenerate from a checkout of the `0.1` tag:

```bash
PYTHONPATH=/path/to/openMWR-0.1/src python tests/tools/generate_checkpoint_01_reference.py
```

Review changes to this reference rather than regenerating it to accommodate a
failed compatibility test.
